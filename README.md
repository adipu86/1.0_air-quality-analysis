# 🌍 Global Air Quality Analysis (2014–2025)

## 📖 Project Overview
This project analyzes global air quality data to understand pollution trends and key factors affecting Air Quality Index (AQI).

## 🎯 Objectives
- Analyze AQI trends over time
- Identify most polluted countries and cities
- Investigate key factors affecting air quality

## 🛠️ Tools Used
- Python (Pandas, NumPy)
- Matplotlib, Seaborn
- Kaggle Notebook

## 📊 Key Insights
- AQI remained relatively stable from 2014–2025
- Significant air quality improvement occurred in 2020 (likely due to COVID-19 lockdowns)
- PM2.5 and PM10 are the strongest contributors to AQI
- Wind speed helps reduce pollution levels

## 📁 Dataset
Dataset from Kaggle:  
https://www.kaggle.com/datasets/ashyou09/world-air-pollution-and-aqi-dataset-20142025
